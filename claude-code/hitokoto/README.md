# hitokoto

A line from [Hitokoto (一言)](https://hitokoto.cn) in a band above the prompt, with its author and source dimmed after it. A new line every 30 minutes; `/hitokoto` fetches one now, `/hitokoto off` and `/hitokoto on` hide and show the band. Options: `categories` (the API's category letters, e.g. `d,i,k` for 文学、诗词、哲学; empty takes any) and `intervalMinutes`.
